# OrganoidVision

OrganoidVision nghiên cứu organoid võng mạc như cảm biến hình ảnh sống dựa trên sự kiện, kết nối với vi lưu, điện tử sinh học, đọc MEA và giải mã neuromorphic.

- Website: [ideas.onlyideas.art](https://ideas.onlyideas.art)
