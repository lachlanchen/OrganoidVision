# OrganoidVision

OrganoidVision erforscht retinale Organoide als lebende ereignisbasierte Bildsensoren, verbunden mit Mikrofluidik, Bioelektronik, MEA-Auslesung und neuromorpher Dekodierung.

- Website: [ideas.onlyideas.art](https://ideas.onlyideas.art)
- Repository: [github.com/lachlanchen/OrganoidVision](https://github.com/lachlanchen/OrganoidVision)
- Begleitprojekt: [OrganoidIntelligence](https://github.com/lachlanchen/OrganoidIntelligence)
