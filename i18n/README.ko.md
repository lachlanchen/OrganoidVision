# OrganoidVision

OrganoidVision은 망막 오가노이드를 미세유체, 바이오전자 인터페이스, MEA readout, 뉴로모픽 디코딩과 연결된 살아 있는 event-based imaging sensor로 연구합니다.

- 웹사이트: [ideas.onlyideas.art](https://ideas.onlyideas.art)
- 저장소: [github.com/lachlanchen/OrganoidVision](https://github.com/lachlanchen/OrganoidVision)
- 동반 프로젝트: [OrganoidIntelligence](https://github.com/lachlanchen/OrganoidIntelligence)
