# OrganoidVision

OrganoidVision explores retinal organoids as living event-based imaging sensors connected to microfluidics, bioelectronics, MEA readout, and neuromorphic decoding.

- Website: [ideas.onlyideas.art](https://ideas.onlyideas.art)
