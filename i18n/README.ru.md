# OrganoidVision

OrganoidVision исследует ретинальные органоиды как живые event-based сенсоры изображения, связанные с микрофлюидикой, биоэлектроникой, MEA-считыванием и нейроморфным декодированием.

- Сайт: [ideas.onlyideas.art](https://ideas.onlyideas.art)
- Репозиторий: [github.com/lachlanchen/OrganoidVision](https://github.com/lachlanchen/OrganoidVision)
- Связанный проект: [OrganoidIntelligence](https://github.com/lachlanchen/OrganoidIntelligence)
