# OrganoidVision

OrganoidVision explores bio-hybrid vision systems that connect retinal organoids, microfluidics, bioelectronic interfaces, and event-based sensing pipelines.

Website: [ideas.onlyideas.art](https://ideas.onlyideas.art)

Companion repository: [OrganoidIntelligence](https://github.com/lachlanchen/intelligence)

The repository currently contains:

- `paper/nature_submission/`: Nature-style manuscript source and compiled PDF.
- `references/`: research notes, sensor-stack blueprints, and deep-research audits.
- `tools/paper_writer/`: local paper-generation and figure-generation workflow scripts.
